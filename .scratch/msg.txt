r4-part5: H tests — cross-instance durable monotonic authority

Adds 6 new tests + a FailingUserDefaults injection fixture proving the
H invariants end-to-end:

- testTwoLiveAuthoritiesShareDurableHighWaterAcrossInstances
  A adopts 500 → B's next reserve on the same domain is > 500 (B's
  in-memory cache seeded at 0 is irrelevant; the durable value wins).

- testConcurrentReservesAcrossLiveAuthoritiesAreUniqueAndMonotonic
  Interleaved reserves from two distinct authorities on same domain
  yield strictly monotonic unique tokens (proves the cross-instance
  coordinator NSLock actually serializes the CAS).

- testRecreatedInstanceContinuesFromDurableState
  A recreated store on same domain does not rewind — subsequent mint
  yields token > prior mint's token.

- testInjectedPersistenceFailureReserveThrowsAndDoesNotPublish
- testInjectedPersistenceFailureMintThrowsAndDoesNotPublish
  FailingUserDefaults silently drops writes to the highwater keys →
  the verified-read after write in reserveNextToken/tryAdopt observes
  the mismatch and throws .persistenceFailure; no session published.

- testUInt64OverflowSurfacesTokenSpaceExhausted
  Pre-seed reservedHighWater = UInt64.max → next reserve overflows via
  addingReportingOverflow → typed .tokenSpaceExhausted, no trap.

- testReleaseCoordinatorDropsDomainLock
  Explicit housekeeping proof: releaseCoordinator removes the static
  registry entry; recreating on same domain registers a fresh lock.

All 26 FarmSnapshotAuthorityTests pass on iPhone 17 simulator.
