# Snapshot Baselines

Reference images for `PrinterControlsSectionSnapshotTests` (Closes
OlyForge3D/PrintFarmer#289). Generated by `pointfreeco/swift-snapshot-testing`.

## Baseline gating (Refs #807)

`PrinterControlsSectionSnapshotTests` short-circuits with `XCTSkip` when a
required PNG is missing. This prevents `pointfreeco/swift-snapshot-testing`'s
"No reference was found on disk. Automatically recorded snapshot…" failure
mode from repeating on every ephemeral CI run without leaving evidence.

- CI runs the suite as-is; missing baselines report as skipped, not failed.
- To record baselines locally, set the escape hatch environment variable
  `PFARM_RUN_SNAPSHOT_TESTS_WITHOUT_BASELINE=1` and run the suite once. The
  library writes new PNGs alongside this README. Verify them visually, unset
  the env var, then commit the PNGs so future CI runs assert against them.

## Regenerating

Baselines are SDK-sensitive (font metrics, blur, system colors). When CI fails
with diff output, regenerate against the CI simulator (iPhone 13, iOS 17):

1. In `PrinterControlsSectionSnapshotTests.swift`, set `isRecording = true` at
   the top of `setUp()` or pass `record: true` per call.
2. Run the suite on the target simulator.
3. Inspect the regenerated PNGs under this directory.
4. Reset `isRecording = false` (default) and commit the new PNGs.

Locally on macOS with a newer SDK (e.g., iOS 26.x), expect diffs against the
CI baselines — regenerate only on the CI sim or in a matching container.
