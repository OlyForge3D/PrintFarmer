Distill: Farm · Queue · Filament

Design reference for epic #3236. On the farm floor, the phone shows the farm, runs the queue, handles filament and scans tags. Analytics, upkeep and reporting stay on the web.

All colours are the dark-mode pf* tokens from Theme/ThemeColors.swift. Light mode uses the same layout with the light tokens.

The three tabs

The app has one shell with no Floor/Oversight split. Scan floats above every tab. Settings, Account and Servers sit behind the avatar. Printers that need attention show a badge on their own card, so the separate Attention and Tasks hubs are no longer needed.

Printer detail: four swipeable pages

The detail view has four pages: Status, Control, Filament and Queue. You can swipe between them or use the segmented header to jump to one. Odometer, history, the Mainsail link, auto-dispatch and setup move to the web, reached through “Open in web ↗”. The homed-axis X/Y/Z badges are removed. A note that the printer isn't homed appears only on the jog pad, where it matters.

iPad

iPad uses a sidebar with the same three destinations. It has no Floor/Oversight groups and no shell picker. The cards use the same adaptive layout as on iPhone, arranged in a grid.

What goes, what stays

Removed code is deleted, not hidden behind flags. Deep links to removed destinations open Farm instead.
