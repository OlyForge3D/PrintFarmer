Control tab: four directions

These mockups replace the current Control panel stack: Preheat, Motion with an "Advanced motion" disclosure, Runtime adjustments, then a "Safety checks" disclosure. All four directions follow the same rules:

  • There is no temperature section. Live temperatures stay on the Status tab and in the card header only.
  • Home XY, Home Z, Motors off and Z-offset are always visible. They are not collapsed into "Advanced".
  • Status never says "Unknown". It says what is true, for example "Not reported · 2 min".
  • Corner radius is 8 px or less. Only the teal accent is used, color always comes with text, touch targets are at least 44 pt, and the E-stop stays pinned.

A · State-driven

The page shows only what can act right now. When the printer is idle, you get setup tasks in order: heat, then move, then calibrate. While it is printing, setup collapses into a single lock note and the page becomes live tuning. Nothing is hidden behind a disclosure.

StrengthThe smallest cognitive load, and it matches the existing lockout rule, so the page reads as deliberate.
RiskThe layout changes when the state changes, so operators have to learn two pages instead of one.

B · Instrument panel with Move, Heat and Tune segments

A segmented control splits the tab into three focused instruments, so each segment fits on one screen with no scrolling. The position readout is a fixed header, like a machine DRO. While printing, Move and Heat stay visible but are marked locked, and the panel opens on Tune.

StrengthThe layout is stable and predictable, nothing scrolls, and there is room for each instrument.
RiskIt adds a second level of tabs under Status / Control / Info. Home and Preheat are one tap further away.

C · Action tiles with a jog sheet

The tab is a grid of named, one-tap jobs. Fine positioning opens a bottom sheet within thumb reach, so the jog pad only takes up the screen while you are using it. Each tile shows its current value as a subtitle.

StrengthThe tab is the easiest to scan, the most one-handed, and the easiest to extend with new actions.
RiskJogging costs one extra tap, and operators who jog constantly may find the sheet slower.

D · Native grouped list

A grouped list in the style of iOS Settings, with named sections: Heat, Motion, Calibration and Live tuning. It works with VoiceOver and Dynamic Type without extra effort, and every action is a full-width row of at least 44 pt. The jog pad is a pushed screen behind "Jog axes".

StrengthThe cheapest to build and the most accessible, and it reads as a native, professional iOS app.
RiskIt is the least distinctive option. It looks like Settings rather than an instrument panel.
