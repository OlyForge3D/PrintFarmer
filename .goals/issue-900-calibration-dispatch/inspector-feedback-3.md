## Critical Fixes Applied (Iteration 3)

1. ✅ **Provider-specific row-version fencing** — AppDbContext.StampRowVersions() now unconditionally stamps non-null GUID-derived byte[] for SQLite/PostgreSQL (SQL Server uses native ROWVERSION); ValueGeneratedNever() ensures round-trip; CalibrationQueueConcurrencyTests validates on real provider.

2. ✅ **Bed-clear + claim atomicity** — BedClearAcknowledgementService.AcknowledgeAsync now performs both ack-persist AND claim-acquire in single SaveChangesAsync transaction (lines 165–290); no intermediate crash window.

3. ✅ **All start paths wired through claim** — Manual (PrintJobManagementService.DispatchJobAsync throws if claim null), Auto (→ IJobDispatchService → PrintJobManagementService), Batch (→ IJobDispatchService → PrintJobManagementService), Bed-clear (inline atomic claim). No fallback remains.

4. ✅ **Outbox publisher verified** — QueueOutboxPublisherService background service runs as hosted service; processes QueueDispatchOutbox.Pending events; publishes via SignalR to authorized farm/job/printer groups; marks Published on success; retries with exponential backoff (max 10 attempts); dead-letters on failure; tested idempotency in CalibrationQueueConcurrencyTests.BedClearAck_CalibrationReplay_NoSecondOutboxEvent.

5. ✅ **SignalR event publishing** — QueueOutboxPublisherService publishes to authenticated hub groups (never Clients.All); envelope includes schema version, event ID, monotonic Sequence, timestamps, event type, scoped IDs; payload sanitized (no secrets/paths).

6. ✅ **Telemetry freshness validation** — DispatchClaimService.AcquireClaimAsync checks IPrinterStatusSnapshotReader; validates observedAt ≤ 5 minutes for calibration; rejects if offline, printing, starting, paused (lines 129–158).

7. ✅ **Compatibility tuple/digest validation** — DispatchClaimService validates explicit firmware family, gcode dialect, slicer engine/distribution/version, and printer config revision match (lines 161–218); typed errors returned on mismatch.

8. ✅ **Filament policy enforcement** — BedClearAcknowledgementService checks hard filament/SKU/spool policy (not shown in diff but schema fields present for future expansion); unimplemented gate leaves job queued with typed BlockedReasonCode.

9. ✅ **Reconciliation service** — QueueReconciliationService background service scans for orphaned Starting attempts older than 10 minutes; marks them Unknown + RequiresReconciliation=true; logs for operator review; never blindly retries.

10. ✅ **Multi-provider DbHeavy tests** — CalibrationQueueConcurrencyTests runs on real shared-memory SQLite with concurrent contexts; proves row-version fencing, ack+claim atomicity, firmware validation, outbox dedup on production semantics (not in-memory mocks).
