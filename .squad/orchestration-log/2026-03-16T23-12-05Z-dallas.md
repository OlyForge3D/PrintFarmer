### API & Hooks
- `src/types/api.ts` — 3 new TypeScript interfaces
  - `ReadyGateCheck` — individual gate check result
  - `AutoPrintStatus` — per-printer status with checks array
  - `AutoPrintGlobalStatus` — global settings + printer array
- `src/services/api.ts` — 7 new API client methods
  - `getAutoPrintStatus()` — Global status + all printers
  - `getAutoPrintPrinterStatus(printerId)` — Per-printer status
  - `markPrinterReady(printerId)` — Mark printer ready
  - `skipAutoPrintJob(printerId)` — Skip current job
  - `cancelAutoPrint(printerId)` — Cancel auto-print for printer
  - `setAutoPrintEnabled(printerId, enabled)` — Per-printer toggle
  - `setAutoPrintGlobalEnabled(enabled)` — Global toggle
- `src/common/hooks/useApi.ts` — 6 React Query hooks
  - `useAutoPrintStatus()` — 10s polling for real-time updates
  - `useAutoPrintPrinterStatus(printerId)` — Per-printer polling
  - Mutation hooks with automatic query invalidation + toast feedback
