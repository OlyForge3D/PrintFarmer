### Key Findings

**Item 1: Camera Control**
- **Competitor State:**
  - OctoPrint/Mainsail: Passive streaming only (no toggle)
  - SimplyPrint: Advanced (toggle per-printer, bandwidth control)
  - 3DPrinterOS: Enterprise-grade (disable for compliance)
  - Bambu: Native integration (tied to cloud account)
  - Obico: Streams to cloud (no local toggle)
- **User Needs:** Bandwidth management, privacy toggle, multi-camera dashboard
- **PrintFarmer Opportunity:** Unified control across Moonraker/OctoPrint/PrusaLink (unique value)
- **Recommendation:** Implement per-printer camera toggle + multi-camera dashboard selection
- **Scope:** Quick win (toggle button on printer card)

**Item 2: Slicer Artifacts**
- **Competitor State:** Low investment across ecosystem
- **User Needs:** Timelapse generation, video storage, failure detection integration
- **PrintFarmer Opportunity:** Core platform feature (unique to farm management)
- **Recommendation:** Phase 3E (full artifact pipeline)

**Item 3: OpenAPI/Swagger**
- **Competitor State:** Table-stakes (all competitors have it)
- **User Needs:** SDK/client generation, third-party integrations
- **PrintFarmer Status:** Already complete (native .NET 10 `AddOpenApi()`)
- **Recommendation:** No action needed

**Item 4: Tag Support**
- **Competitor State:** Limited implementation
- **User Needs:** Job organization, filtering
- **PrintFarmer Opportunity:** Projects feature provides better structure
- **Recommendation:** Defer in favor of Projects (better organizational model)

**Item 5: OrcaSlicer Types**
- **Competitor State:** Bambu ecosystem unique (not general need)
- **User Base:** OrcaSlicer is niche in farm context
- **PrintFarmer Opportunity:** Specialized integration (Phase 3E)
- **Recommendation:** Phase 3E (lower priority than camera/artifacts)
