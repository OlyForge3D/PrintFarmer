## Related Architecture Decisions

This documentation synthesizes:
1. Three-layer design system (CSS variables → Tailwind → React)
2. Zero hardcoded colors (all via pf-* tokens for dynamic theming)
3. WCAG 2.2 AA compliance built-in
4. Component library consolidation (40+ in single ui/ directory)
5. Dynamic theming without rebuilds
