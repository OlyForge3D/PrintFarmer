## Test Patterns & Infrastructure

### Setup
- Vitest with React Testing Library (RTL)
- Mock locationService with vi.mock()
- MSW for API mocking (where applicable)
- userEvent for realistic interactions
- waitFor for async operations

### Query Patterns
- `getByRole()` preferred for semantic queries
- `getByLabelText()` for form associations
- Avoid `getByText()` when role exists
- Use `getAllByRole()` for multiple elements

### Mocking Strategy
- **Service mocks:** `vi.mock('@/services/locationService')`
- **Dynamic imports:** `const { getLocationTree } = await import('@/services/locationService')`
- **Child component mocks:** When testing parents, mock children for isolation
- **Confirmation modal:** Renders inline (no portal), works with waitFor
