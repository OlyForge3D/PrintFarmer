## Key Design Decisions

### 1. Two-Tier Status Badges
- **Enabled Badge:** Administrative state (always visible)
- **Health Badge:** Runtime state (only after manual test)
- **Rationale:** Clear separation of concerns, prevents stale cached health data

### 2. On-Demand Health Checks
- **Chosen:** Mutation (not query), requires manual trigger
- **Alternative:** Periodic query polling (rejected — stale data risk)
- **Rationale:** Health can change rapidly, users need fresh data for decisions

### 3. Enabled-Only Dropdown in Printer Edit
- **Chosen:** Filter dropdown to enabled servers only
- **Rationale:** Prevents user confusion, blocks accidental assignment to offline servers
- **Disabled servers visible in management view:** Provides visibility for troubleshooting

### 4. Delete Confirmation with Count
- **Chosen:** Modal warning shows affected printers count
- **Rationale:** Users informed of consequences before deletion
- **Safety:** Encourages reassignment before deletion
