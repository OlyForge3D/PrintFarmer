## Design Decisions

✅ **Custom CSS Grid** — No FullCalendar dependency (constraint: no new npm deps)  
✅ **Status Color Mapping** — active=green, paused=yellow, cancelled=red, completed=gray  
✅ **Browser Timezone Default** — Reduces friction in common case  
✅ **Conditional Interval Field** — Progressive disclosure for recurrence config  
✅ **Job ID Text Input** — Users copy-paste IDs; dropdown would require separate API
