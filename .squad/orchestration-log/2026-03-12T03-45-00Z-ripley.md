## Architecture Decisions

### Feature Folder Separation
- Created `src/features/analytics/` as separate namespace from existing `src/features/statistics/`
- Rationale: Statistics page = quick KPI overview; Analytics = power user deep-dive business intelligence
- Both routes coexist: `/statistics` + `/analytics` serve different personas

### Reuse & Patterns
- Reused existing `useStatistics` hooks for base data
- Reused existing Recharts chart components
- Added export methods to `ApiClient` (require `responseType: 'blob'`)
- Correlation GET endpoints use direct `apiClient.get()` pattern (no new class methods)

### Component API Design
- **Tabs compound pattern:** String `id` props (not index-based)
- **Predictive alerts:** Auto-hide when empty, positioned above KPI cards for visibility
- **staleTime strategy:** 300s for correlation (reference), 60s for alerts (dynamic)
