## Deliverables

### Code
- `CostDashboardPage.tsx` — Main page component with:
  - Summary cards (total cost, avg cost per job, total jobs, total hours)
  - Sortable table: costs by printer (name, cost count, total cost, avg cost)

- **Route** at `/statistics/costs` in main routing configuration

### Design Decisions (Documented in decisions.md)
1. **Inline Type Imports** — Use `import("@/types/api").TypeName` in return types to avoid ESLint errors
2. **5-minute Stale Time** — Cost data is stable (updated on job completion), not real-time
3. **Currency Formatting** — Use `Intl.NumberFormat('en-US', { style: 'currency', currency: 'USD' })`
4. **KpiCard Component Reuse** — Pattern from StatisticsPage for visual consistency
5. **Flat Navigation** — "Cost Analytics" link adjacent to Statistics, not nested
6. **Flat Query Keys** — `['costs', 'summary']`, easy to group invalidate
