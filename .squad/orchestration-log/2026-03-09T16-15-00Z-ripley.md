## Key Decisions

### npm overrides with >= ranges
- **Rationale:** Exact version pins (e.g., `minimatch: 10.2.3`) lock vulnerabilities in place. Using `>=` allows semver-compatible patches to auto-update.
- **Impact:** Future minor/patch releases in minimatch/dompurify will be pulled automatically without manual override updates.
- **Risk Mitigation:** Overrides are the correct npm mechanism for forcing transitive dependency versions when direct parents (jspdf, eslint, typescript-eslint) haven't released updates yet.
