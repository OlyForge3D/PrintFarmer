# Contract Drift Gate

Issue: [#2243](https://github.com/OlyForge3D/PrintFarmer/issues/2243) (part of epic
[#2237](https://github.com/OlyForge3D/PrintFarmer/issues/2237)).

## What it checks

`scripts/ci/check-contract-drift.mjs` is a deterministic, allowlist-backed gate over the
canonical wire-contract corpus at `fixtures/wire-contracts/` (introduced by
[#2238](https://github.com/OlyForge3D/PrintFarmer/issues/2238)). It runs three checks:

1. **camelCase enforcement on `api/**` fixtures.** Every property key in every
   `fixtures/wire-contracts/api/<family>/*.json` fixture must be camelCase, matching the
   JSON casing PrintFarmer's own `JsonStringEnumConverter`/System.Text.Json configuration
   emits. A family may only violate this with an explicit, reviewed exception (see below).
2. **Mandatory allowlisting of `native-slicer/**` families.** OrcaSlicer's native payload
   shape (snake_case, vendor-defined) is fundamentally different from PrintFarmer's own
   DTOs. Rather than special-casing snake_case in the checker, every
   `native-slicer/<family>` is required to carry an exception entry that documents *why*
   it's exempt — so a new native family can never slip in unreviewed.
3. **Producer-coupling.** If a fixture file changes in a diff (PR or push) but no
   corresponding backend/worker source path (`src/api/`, `src/backends/`, `src/slicer/`,
   `src/discovery/`, `src/migrations/`, or a `.cs` test under `src/tests/`) changed in the
   same diff, the gate fails. Fixtures are only ever regenerated by
   `WireContractFixtureWriter` running against real serialization code
   (`WIRE_CONTRACT_REGEN=1`); a fixture edited by hand with no producer change is the
   corpus-drift shape the gate exists to catch (see #2232).

The script exits `0` with zero findings, or `1` and prints every finding it detected.

## The exception allowlist

`scripts/ci/contract-drift-exceptions.json` is the **reviewed** escape hatch. Every entry
must carry:

- `boundary` — the case- or check-specific identifier the exception applies to (e.g.
  `native-slicer:filament`, or `api:<family>:<key>` for a single-key casing exception).
- `rationale` — why the exception is necessary and cannot be fixed at the source.
- `owner` — a `squad:<member>` string naming who is accountable for the exception.
- `reviewTrigger` — what change should prompt a fresh review of this exception (e.g. "any
  new native-slicer family" or "next OrcaSlicer profile schema bump").
- `expiry` — an ISO date after which the exception is stale and must be re-reviewed.
  `check-contract-drift.mjs` treats an expired entry as if it didn't exist, so drift it
  was suppressing reappears as a finding.

Adding an entry to this file is itself a reviewable code change — it is not a
self-service bypass. A PR that both introduces drift and quietly adds the exception that
hides it should fail review on that basis alone.

## Where it runs

`.github/workflows/contract-drift.yml` is a **new, standalone** workflow — it does not
modify `.github/workflows/ci.yml`, `deployment-tests.yml`, or `ios-pr-ci.yml`. It:

1. Checks out with full history (`fetch-depth: 0`) so it can diff against the PR's merge
   base / the previous push.
2. Installs Node from `.nvmrc` and runs `npm ci` (for the `js-yaml` dev dependency used by
   this workflow's own self-tests).
3. Reuses the existing `scripts/ci/compute-change-set.sh` (unmodified) to compute the
   changed-file set for the current event.
4. Runs `scripts/ci/tests/test-check-contract-drift.mjs` and
   `scripts/ci/tests/test-contract-drift-workflow.mjs` (`node --test`).
5. Runs `scripts/ci/check-contract-drift.mjs` against the real corpus, with the computed
   changed-file set wired in via `CONTRACT_DRIFT_CHANGED_FILE`, and fails the job on any
   finding.

## Filing findings

If the gate ever reports a real finding, it is **not** fixed inline as part of an
unrelated PR. Per the issue's acceptance criteria, each finding is filed as its own
GitHub issue linking back to the offending commit/PR, and either fixed there or
resolved via a new, reviewed allowlist entry.
