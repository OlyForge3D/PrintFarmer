# PrintFarmer UI Design System Requirements

⚠️ **CRITICAL**: All new UI components in this workspace package MUST follow the PrintFarmer design system.

## Design System Rules

### 1. CSS Color Variables (DO NOT use generic Tailwind colors)

**Reference File**: `src/Web/ReactApp/src/styles/theme.css`

Use PrintFarmer CSS custom properties instead of hardcoded Tailwind colors:

- **Backgrounds**: 
  - `bg-pf-bg-0` - Main dark background
  - `bg-pf-bg-1` - Secondary darker background  
  - `bg-pf-bg-2` - Tertiary lighter background
  - `bg-pf-panel` - Panel/card background
  
- **Text Colors**:
  - `text-pf-text-primary` - Primary text
  - `text-pf-text-secondary` - Secondary text
  - `text-pf-text-muted` - Muted/disabled text

- **Borders**:
  - `border-pf-border` - Standard border
  - `border-pf-border-light` - Light border
  - `border-pf-border-medium` - Medium border
  - `border-pf-border-dark` - Dark border

- **Interactive States**:
  - `bg-pf-accent-2` - Primary action button (blue)
  - `bg-pf-accent` - Success/secondary action (green)
  - `bg-pf-error` - Error state
  - `bg-pf-error-bg` - Error background
  - `bg-pf-warning` - Warning state

### 2. DO NOT Do This ❌

```tsx
// ❌ WRONG: Generic Tailwind colors
<div className="bg-blue-600 text-white p-4">Button</div>
<div className="bg-red-50 border border-red-200">Error message</div>
<div className="bg-gray-50 text-gray-600">Text</div>

// ❌ WRONG: Mix of systems
<button className="bg-blue-600 hover:bg-pf-accent-2">Confusing</button>
```

### 3. DO This Instead ✅

```tsx
// ✅ CORRECT: Use PrintFarmer design system variables
<div className="bg-pf-panel text-pf-text-primary p-4 border border-pf-border">
  Content
</div>

// ✅ CORRECT: Consistent styling
<button className="bg-pf-accent-2 text-pf-text-primary hover:bg-pf-accent-2-hover">
  Action
</button>

// ✅ CORRECT: Error styling
<div className="bg-pf-error-bg border border-pf-error rounded p-4">
  <AlertCircle className="text-pf-error" />
  <p className="text-pf-error">Error message</p>
</div>
```

### 4. Component Reference Implementation

**See**: `src/Web/ReactApp/src/pages/ImportOfficialProfilesPage.tsx`

This page demonstrates the correct way to style PrintFarmer features:
- Uses `PageTemplate` wrapper
- Imports `Button`, `Alert`, `FormField`, `Select` components
- All text uses `text-pf-*` classes
- All backgrounds use `bg-pf-*` classes
- All borders use `border-pf-*` classes

### 5. Interactive Elements Checklist

When adding new UI components, ensure:

- [ ] All text colors use `text-pf-text-*` or inherit from parent
- [ ] All background colors use `bg-pf-*` variables
- [ ] All border colors use `border-pf-*` variables
- [ ] Buttons use `bg-pf-accent-2` for primary actions
- [ ] Error states use `bg-pf-error-bg` + `border-pf-error` + `text-pf-error`
- [ ] Success states use `bg-pf-accent` (green)
- [ ] Hover states respect PrintFarmer design (check theme.css for `-hover` variants)
- [ ] Disabled states use `bg-pf-border` with reduced opacity
- [ ] Form inputs have `accent-pf-accent-2` for checkboxes/radio buttons

### 6. Testing Your Changes

After styling updates:

1. **Build React app**: `npm run build` in `src/Web/ReactApp/`
2. **Visual verification**: Start dev server and navigate to component
3. **Dark theme check**: Ensure component looks correct on dark background
4. **Contrast check**: Verify text is readable against backgrounds
